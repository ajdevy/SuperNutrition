# Epic 3 local visible-food scope — superseded

**Status:** the earlier detector-specific scope was withdrawn on 2026-11-02
under repository-owner decisions D-11 and D-13.

The current local inference path retains Food-101 dish classification only.
It does not identify meal components, estimate grams, or activate a component
model. The removed detector implementation, benchmark outputs, and model
artifacts are not part of the SuperNutrition project history after cleanup.

G-3 remains open for any future component or mass capability. A future
implementation requires a separately cleared model, consented weighed data,
physical evidence, and the required approval bundle.
