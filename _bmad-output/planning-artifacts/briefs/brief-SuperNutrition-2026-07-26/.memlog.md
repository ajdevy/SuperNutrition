- (decision) Product working name is NutriArch; the repository remains SuperNutrition.
- (decision) The product targets Android and iOS from a Kotlin Multiplatform codebase.
- (decision) Compose Multiplatform is used for shared UI where platform fit permits.
- (decision) The first product capability is food identification from photos with both local and remote inference.
- (decision) Local inference and remote inference must be separate implementation tracks so different developers can work independently.
- (decision) Local inference is capability-aware and may use different implementations by platform and device tier.
- (decision) BMAD artifacts govern implementation planning before code work begins.
- (decision) Implementation should use the vendored AlexGladkov Claude Code agents, especially kotlin-multiplatform-developer.
- (decision) Both local and remote inference are first-release scope, resolving the previous phasing question because the user explicitly requested both as the first features.
- (decision) The prior React Native Expo prototype is reference evidence only; Kotlin Multiplatform and Compose Multiplatform are the selected implementation direction.
- (decision) Model-generated numeric nutrition fallback is rejected; ungrounded results must abstain or remain explicitly unresolved.
- (decision) Confirmation and correction are first-release requirements because single-photo portion and hidden-ingredient uncertainty cannot be made safe by model confidence alone.
- (decision) Product scope is assisted nutrition estimation, not medical measurement, allergen detection, or exact single-photo calorie measurement.
- (decision) Remote upload requires explicit consent and raw images are not retained by default.
- (assumption) NutriArch remains the working product name while SuperNutrition remains the repository name; trademark and store naming are still open.
- (assumption) The first release is an internal beta with no login or persisted meal history.
- (assumption) Public launch geography and the production nutrition dataset are deferred until the evaluation spike supplies evidence.
- (event) Product brief finalized after source reconciliation and editorial review
- (change) Initial audience is Tier 1 country users; beta is English-first and localization-ready, while the exact launch-country list remains open because Tier 1 has no universal definition.
