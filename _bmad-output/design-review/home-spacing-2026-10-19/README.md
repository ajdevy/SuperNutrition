# Home — новые отступы и компактная шапка

Откройте [HTML-галерею](index.html) и [заметки для дизайнера](DESIGNER-NOTES.md). Здесь девять популярных портретных размеров и 18 настоящих Android-снимков при 100% и 200% системного текста. Предыдущие галереи сохранены отдельно.

Название Super Nutrition и дата убраны. Между независимыми секциями 16 dp, по бокам телефонной композиции 24 dp. Размеры шрифтов сохранены. [Кадр до изменения](before/720x1560-320dpi/font-100/home.png) показывает прежнюю сборку и не входит в 18 результатов.

При 100% весь Home помещается на всех девяти размерах. При 200% три планшетных варианта помещаются, шесть телефонных требуют читаемой прокрутки. Большие свободные области планшетов отмечены для оценки пропорций. Исходные PNG не обрезаны и не масштабированы при сохранении.

Проверка: Android API35 x86_64 на единственном эмуляторе SN_Final_Verification_35_20261018, viewport overrides. Это не проверка конкретных моделей устройств или iOS. Настройки гостя восстановлены по сохранённому baseline. Физический телефон не использовался.

В папке `verification/` сохранены свежие XML и записи команд: 177 JVM-тестов UI, 4 core UI, по 43 Android-теста для poc, production и uiAcceptance; ошибок и пропусков нет. Сборка production, scoped detekt и явная компиляция общего iOS Arm64-кода прошли. Общий корневой quality-gate и iOS runtime здесь не заявляются. Python-скрипты: 32 теста проходят. Два независимых просмотра изменений завершены; три замечания к инструментам исправлены.

[Проверка галереи](gallery-validation.json) подтверждает совпадение всех 18 записей просмотра с SHA-256 PNG, один ожидаемый production APK, 84 локальные ссылки и 14 сценариев настоящего встроенного JS в изолированной Node VM. Визуальная проверка HTML в браузере недоступна: политика браузера отклонила локальный file URL; обход не использовался. Все PNG визуально просмотрены непосредственно после съёмки.
