# Synthetic meal scenarios

These fictional, text-only scenarios support exploratory review and contain no
real meal photos or user records. They are not calibrated ground truth and
must not be used as production accuracy evidence.

| Scenario | Made-up meal description | Intent |
| --- | --- | --- |
| `synthetic-breakfast` | Scrambled eggs, toast, oatmeal, and mixed berries | Common breakfast foods |
| `synthetic-salad` | Grilled chicken, lettuce, cucumber, carrot, and cherry tomato | Mixed salad with a named protein |
| `synthetic-grain-bowl` | Brown rice, tofu, broccoli, and roasted pepper | Plant protein and grains |
| `synthetic-pasta` | Pasta with tomato sauce, mushrooms, and spinach | Cooked mixed dish |
| `synthetic-ambiguous-plate` | Rice, beans, leafy greens, and a small portion of roasted vegetables | Ambiguous ingredient identity |

No photographs are included in this directory. For image-analysis evaluation,
use a properly licensed public dataset or create a synthetic image fixture and
record its provenance before adding it to the repository.
